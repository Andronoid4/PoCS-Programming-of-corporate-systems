# Туристический путеводитель

Веб-приложение на ASP.NET Core MVC для просмотра информации о городах и достопримечательностях.

## Требования

- .NET 8.0 SDK
- Rider или другая IDE для .NET

## Запуск приложения

1. Откройте проект `TravelGuide.csproj` в Rider
2. Восстановите пакеты:
   ```bash
   dotnet restore
   ```
3. Запустите приложение:
   ```bash
   dotnet run
   ```
4. Откройте браузер и перейдите по адресу `http://localhost:5000`

## Структура проекта

```
TravelGuide/
├── Controllers/
```

## Функциональность

- **Список городов**: Главная страница со списком всех городов, кратким описанием и поиском по названию
- **Информация о городе**: Подробная информация о городе (название, регион, население, история, герб, фото) + список достопримечательностей
- **Достопримечательности**: Список достопримечательностей города с фото и описанием
- **Информация о достопримечательности**: Детальная информация (название, история, фото, часы работы, стоимость)

## База данных

Приложение использует SQLite с Entity Framework Core. База данных создаётся автоматически при первом запуске и заполняется тестовыми данными (Москва, Санкт-Петербург, Казань).

## Изображения

Изображения могут храниться в папке `wwwroot/images/`. В демонстрационных данных используются URL-заглушки (placeholder.com), которые можно заменить на реальные изображения.
